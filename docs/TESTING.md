## 3. 上下文与复测关键回归结果

120 项表中的上下文与错题组（X-001～X-020）全部通过，其中核心结果包括：

- “上一道题再讲一下”能切回上一有效题，右侧学习内容同步更新；
- 在切换到历史题后输入“继续”，仍围绕被选中的历史题；
- “第一题”“第二题”可以定位到指定历史题，不补答其他题；
- “集合那道题”等主题指代可以定位到对应题目，而不是机械选择最近题；
- AI 生成题可以进入历史题导航并恢复教学分类；
- 短追问“为什么 / 再解释一下 / 继续”不会被误当成新题；
- 未订正错题不能直接复测；
- 完成订正后可以生成同核心知识点、不同题面的复测题；
- 正确复测答案能进入答案诊断并记录结果；
- 错误复测答案不会被无条件标记为通过；
- 删除会话后，学习回顾不会继续展示已删除会话产生的孤立学习事件。

当前代码还进一步支持倒序题号、上一/下一题、前后多步、第一/最后/当前题、组合导航，并区分“第 2 小题/第 2 问”和会话历史题号；这些属于当前上下文解析实现能力。

## 4. 核心验收链

```text
文字题 / 图片题 / AI出题
→ 知识识别
→ 提示式辅导
→ 完整解析（用户明确要求时）
→ 记为错题
→ 完成订正
→ 原错题作为结构化参照生成复测题
→ 提交本次复测答案
→ 答案诊断并记录复测结果
```
