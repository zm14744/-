# 权威资料与核验来源

本文件列出当前代码与知识图谱说明中采用的官方/权威来源。

## 离散数学

1. 高等教育出版社《离散数学（第3版）》  
   https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=658daaba74ce561611bd9a4f

2. MIT OpenCourseWare — Mathematics for Computer Science  
   https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/

3. Kenneth H. Rosen — *Discrete Mathematics and Its Applications*, McGraw Hill  
   https://www.mheducation.com/highered/product/discrete-mathematics-and-its-applications-rosen.html

## DeepSeek

1. Chat Completions API  
   https://api-docs.deepseek.com/api/create-chat-completion/

2. DeepSeek API Documentation  
   https://api-docs.deepseek.com/

当前官方 Chat Completions API 列出的模型包括 `deepseek-v4-flash`、`deepseek-v4-pro`、`deepseek-v4-flash-vision-exp`；图像输入支持 `image_url` 与 base64 data URL。
